# Curso RSI - Ciberseguridad aplicada con IA

Este repositorio contiene las actividades prácticas del curso de Responsable de Seguridad de la Información (RSI). Su objetivo es mantener organizados y versionados el código, la documentación y las evidencias generadas durante el curso.

## Organización del repositorio

Las actividades se guardan dentro de `actividades-clase/`. Cada actividad utiliza la siguiente estructura:

- `codigo/`: scripts y archivos desarrollados durante la actividad.
- `evidencias/`: capturas y demás pruebas de los resultados obtenidos.
- `informes/`: informes elaborados para documentar la actividad.
- `bitacora.md`: registro del proceso, comandos, decisiones y reflexiones.

## Convención de evidencias

Las evidencias se nombran con el formato:

```text
EVI-YYYY-MM-DD-NN-descripcion.ext
```

Este formato permite identificar la fecha, el orden y el contenido de cada evidencia.

## Control de versiones

Git se utiliza para conservar la trazabilidad de los cambios. Cada actividad debe cerrarse con un commit descriptivo y sin incluir contraseñas, archivos `.env` ni otra información sensible.
