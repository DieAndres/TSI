## Resumen

Se preparó el entorno de trabajo para las actividades prácticas del curso. Se verificaron Visual Studio Code, Git, Python y pip. Node.js y OpenCode no se instalaron porque se utilizó Codex como alternativa de asistencia con IA.

## Script desarrollado

Se creó `codigo/hola.py`, un script Python que utiliza `argparse` para recibir el argumento `--nombre` y mostrar un saludo. La ejecución realizada fue:

```powershell
python actividades-clase\Actividad_01\codigo\hola.py --nombre RSI
```

El resultado fue:

```text
Hola, RSI!
```
